# mormy_v3 원본 분석

## 요약

원본은 Next.js 16, React 19 기반의 단일 아동용 수학 앱입니다. 화면 대부분과 상태 전이가 `mormi-web/app/MoramiApp.tsx`에 모여 있고, 수학 콘텐츠는 `math-curriculum.ts`와 `morami-content.ts`에 정적으로 정의되어 있습니다.

## 실제 구조

| 영역 | 파일 | 역할 |
|---|---|---|
| 화면 상태 머신 | `app/MoramiApp.tsx` | 과정 선택, 10회 반복, 모르미 가르치기, 별노트, 완료 |
| 커리큘럼 | `app/math-curriculum.ts` | 4개 교육과정 영역, 총 36개 세션 |
| 문제 콘텐츠 | `app/morami-content.ts` | 문제, 선택지, 시각 자료, 생활 문제 |
| 모르미 응답 | `app/api/morami/respond/route.ts` | Anthropic 호출, 실패 시 결정형 대체 문구 |
| 리포트 | `app/report/ReportDashboard.tsx` | 기기 로컬 학습 기록 표시 |
| 스타일 | `app/globals.css` | 민트·크림·노랑·보라 팔레트와 둥근 촉각형 UI |

## 원본 학습 동선

```text
수학 과정 선택 → 혼자 10번 → 모르미에게 설명 → 별노트
→ 모든 세션에 붙은 일반 생활 게임 3개 → 완료
```

## 이번 버전의 변경

- 최초 1회 온보딩을 추가했습니다.
- 기본 시작 화면을 `집`으로 바꿨습니다.
- 카페 준비 과정은 `돈 세기`, `가격 더하기`, `거스름돈`, `돈 종합` 네 개입니다.
- 네 과정을 전부 끝내기 전에는 외부의 카페가 잠겨 있습니다.
- 기존의 세션별 일반 생활 게임 연결을 끊고, 외부 목적지 안에서 맥락 있는 활동을 하도록 바꿨습니다.
- 카페는 설명, 메뉴 선택, 돈 구성, 주문 완료 순서입니다.

## 현재 저장 방식과 다음 단계

현재 진행도와 리포트는 `localStorage`에 저장됩니다. 파일럿 이후 FastAPI와 PostgreSQL을 연결할 때는 동일한 화면 상태를 유지하고 저장소만 API로 교체하면 됩니다. API 계약은 `docs/backend-contract.md`에 정의했습니다.
